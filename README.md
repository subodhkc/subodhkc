# SubodhKC.com

Public website for Subodh KC, Enterprise AI Advisor and AI Systems Architect.

## Positioning

**Turn consequential AI decisions into defensible operating choices.**

**From possibility to decision. From decision to production.**

Commercial architecture:

`Diagnose -> Advise -> Architect / Build -> Assure`

Canonical brand and voice owners:

- `docs/BRAND_CANON.md`
- `docs/CONTENT_VOICE_CANON.md`
- `.windsurf/rules/brand-positioning.md`
- `.windsurf/rules/editorial-voice.md`

## Development

```bash
npm install
npm run dev
npm run build
```

The site uses Next.js 16 App Router, React 19, TypeScript, Tailwind CSS, Supabase, Stripe, and Resend.

## Guardrails

- Preserve existing commercial entitlements, billing identifiers, service terms, and subscriber access.
- Keep enterprise qualification separate from self-service checkout.
- HAIEC means High Assurance In Every Consequence.
- HAIEC is not a certification authority and does not imply universal safety or compliance.
- Missing evidence remains an explicit boundary on the claim.
- Do not expose private member routes in the sitemap or search index.
