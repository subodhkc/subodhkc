Challenge model

Live path

AI system → enforcement points → telemetry. Enforcement points may observe, evaluate or refuse an action.

Governance side

Control register, stateless evaluator, evidence ledger and control tests turn signals into evidence tied to a control and run.

Architecture habit

Separate the decision from enforcement. Telemetry records; evaluator judges; ledger binds evidence; control tests answer the question.

The three controls

7AIA-LOG-001

Automatic event recording

Event driven

Measure expected-event coverage, gaps between consecutive events and tolerated exceptions. Evidence: expected IDs, events, timestamps and run links.

9AIA-ARC-006

Drift and performance

Continuous

Measure relative drop from a frozen baseline per comparable window. Evidence: baseline, live values, windows, alerts, owner and response.

16ACN-COST-001

Per-run spend cap

In transaction

Measure reconciled input + output tokens across all agents and retries for the run. Evidence: call IDs, token counts, budget version and stop records.

Required build sequence

  1. Choose one or more controls. One completed control is the minimum.
  2. Declare the metric, limit, exception tolerance, measurement basis, owner, version and date before the assessed run.
  3. Decide when the control is checked: after the run, continuously or inline.
  4. Build the control at an enforcement point and emit records bound to control, threshold version and run.
  5. Build the control test / evaluator that recomputes the measure, reconciles expected vs observed, counts exceptions and returns a verdict.
  6. Run one passing case and one breaching case. Do not move the threshold to make a run pass. Record what did not close.

How judging works

Axis 1 · Completion

How many of the three controls are completed end to end.

Axis 2 · Quality

Live test, architecture, evidence quality and honest treatment of failures / gaps.

Axis 3 · Bonus

Additional controls, continuous compliance, adversarial testing and a second or additional enforcement point.
